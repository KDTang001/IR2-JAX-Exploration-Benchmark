2026-11-09 用户指出原版 IR2 动作应在当前节点一跳邻接节点中选择。核对 multi_robot_worker.py 的 edge_inputs[current_index]、select_node 和直接位置更新，以及 graph_generator.py 的碰撞检查连边后确认：当前 JAX 环境的全已知连通域候选与截断栅格路径执行改变了动作语义。新训练已在最近完成的 98304 动作 checkpoint 后停止，保留恢复文件。下述优化对照仍是该简化环境中的有效工程记录，但不得当作 IR2 动作语义一致的训练结果。后续须先对齐候选图邻接、单步到达、边长代价与 PLAN 的含义，再决定重新训练；当前权重不能直接当作新动作空间的续训起点。

用户已批准实施。保留现有模型、任务语义和固定 PLAN 预训练，只改优化调度与诊断。

- [x] 输出策略 KL、裁剪比例、熵、价值误差、解释方差、梯度范数及实际优化步数。KL 初始阈值 0.02，小批次更新前检查，整遍后在全批上检查，超阈值停止剩余更新。
- [x] 微型与正式 A 入口使用同一优化调度。默认配置保留全批更新，旧配置身份不变。新配置单独绑定身份。

## 已记录结果

2026-11-09，25 项相关检查通过，耗时 502.45 秒，Ruff 检查通过。普通 A 入口和原尺寸多地图池入口均覆盖；新小批次设置的恢复检查与连续训练一致。旧全批默认值的配置身份保持不变，配置迁移只允许 minibatch_sequences 与 target_kl 两项改变，原参数、优化器、环境、课程游标和随机数状态均保留。

从 75776 动作的同一 checkpoint 出发，两组分别追加 4096 个动作。全批组每批优化 4 次，小批次组每批优化 32 次，每条有效样本均使用 4 遍。第二批全批更新耗时 0.770 秒，小批次 2.016 秒；整批分别 55.417 和 56.804 秒。小批次两批 KL 分别 0.002520 和 0.006488，均未触发 0.02 阈值。阈值按更新前小批次及每遍结束后的全批诊断检查，发现越界后停止后续提交，并非保证任何单步更新都不越界。

留出 easy 地图以种子 10000、10001 对照前 64 轮，保持原 512 轮环境时间归一化，录像标记为片段。全批末帧覆盖分别 12.384%、10.895%，小批次为 12.123%、12.472%。这是短诊断，不作为最终协作提升证据，后续仍需固定验证集评估。
