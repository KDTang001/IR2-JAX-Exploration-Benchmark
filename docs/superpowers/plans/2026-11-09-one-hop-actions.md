# 一跳动作修正与重新训练

历史记录：本次简化一跳训练的模型和 GIF 已在后续 IR2 一致性修正中按用户要求清理；当前实现见 [IR2 动作与观测一致性修正](2026-11-09-ir2-observation-parity.md)。

用户已批准修正动作、删除旧产物并从新初始化训练。队友图融合为可选项，自身历史始终保留。

- 动作由当前节点的一跳邻接点组成。沿已知自由空间中的无碰撞直线，一次事件完整到达终点，距离按欧氏边长累计。不再用全图 BFS 选择远处目标并截断移动。
- 密集节点沿原版 50×50 均匀网格生成，按有效地图尺寸取整。邻居按距离选择后检查障碍和未知格，候选数含等待位置为 30。保留自身历史节点，局部密集节点窗口为 80，全局历史边范围为 160。确定性等距顺序按坐标定义。此阶段对齐一跳动作语义，不声称完整复现原版图维护、合并和 rendezvous utility。
- global_graph_fusion 默认 false。true 时仅从成功收到的 MAP_DELTA 显式地图消息中提取已知自由空间的均匀网格节点，合入自己的历史图。位置或 PLAN 消息不能触发融合。只根据自身已知地图建立边。没有免费读取队友内部图，也不新增隐式全图广播。历史存储容量固定并记录在配置中。
- PLAN 只声明本次选定的一个邻接目标，有效长度为 1；未决的后续动作不伪造为五步路径。发送顺序仍是选点、移动、感知、发送，因此收到的是该次行动意图快照，不是未来五步承诺。
- 同步真实环境、策略计划编码与想象环境的导航语义，累计距离改为浮点。旧栅格路径模式只保留为显式参考模式，正式新配置使用一跳模式，新身份阻止旧 checkpoint 被当成新实验恢复。
- 集中验收候选局部性、碰撞与未知遮挡、完整到达、欧氏距离、非法动作拒绝、PLAN 有效长度、个人历史保留、付费图融合，以及真实更新与恢复。做原尺寸采集实测，不扩展无关测试。
- 验收后删除旧训练 checkpoint、回放、GIF 和旧实验输出，保留源代码、地图、IR2 对照权重及一份变更记录。重新生成训练验证配置，从随机初始化开始，保存探索 GIF，延续既有两天截止时间。
